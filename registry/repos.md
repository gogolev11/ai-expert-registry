## Экономия контекста и понимание кода

### graphify
- **id:** `graphify`
- **Тип:** репозиторий (инструмент + Skill для coding-агентов)
- **Что это:** превращает кодовую базу (а также документацию, SQL-схемы, конфиги, PDF) в граф знаний, по которому агент задаёт вопросы и прослеживает связи, а не перечитывает файлы. Код разбирается локально через tree-sitter (~40 языков) без вызовов модели; документы и картинки — опционально через выбранную вами модель. Каждая связь помечена `EXTRACTED` (найдена явно) или `INFERRED` (выведена).
- **Когда полезно:** большой репозиторий, агент тратит много токенов на «поиск по файлам»; нужно понять архитектуру чужого кода.
- **Ограничения и риски:** [вендор] построение графа по коду не тратит токены модели; прямых замеров экономии токенов в README нет — измерить на своём проекте. PyPI-пакет называется `graphifyy` (две y) — остерегаться похожих имён. Обогащение документов отправляет их выбранному LLM-провайдеру.
- **Факты:** `safishamsi/graphify`, ~124.6k ★, ~12k форков, Apache-2.0 + MIT, активная разработка (ветка v8); интеграции с 20+ агентами (Claude Code, Cursor, Codex, Gemini CLI, Copilot CLI, Aider…). Телеметрии нет по README.
- **Метка:** ADAPT — сильный кандидат, но установочный скрипт `graphify install` ещё не прочитан.
- **Статус:** active
- **Источники:** https://github.com/safishamsi/graphify
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### microsoft/markitdown
- **id:** `markitdown`
- **Тип:** репозиторий (утилита + MCP-сервер)
- **Что это:** превращает PDF (без распознавания сканов), Word, PowerPoint, Excel, HTML, CSV/JSON, EPUB, картинки, аудио и YouTube в Markdown. Модели читают Markdown точнее и тратят на него меньше токенов, чем на исходные форматы. Есть MCP-сервер `markitdown-mcp` с одним инструментом `convert_to_markdown`.
- **Когда полезно:** агент работает с пачкой документов (договоры, отчёты, таблицы); подготовка источников для базы знаний (см. `methods.md` → `llm-wiki-karpathy`).
- **Ограничения и риски:** [вторичный] в HTTP-режиме MCP-сервера нет авторизации, а инструмент читает локальные файлы и скачивает URL — держать только на localhost. Сканы без OCR не распознаёт. Цифры вида «−70 % токенов» из соцсетей — не замер.
- **Факты:** MIT; подключение к Claude Code — `claude mcp add markitdown -- uvx markitdown-mcp` [вторичный].
- **Метка:** ADAPT
- **Статус:** active
- **Источники:** https://github.com/microsoft/markitdown · [вторичный] https://mcp.directory/blog/markitdown-mcp-complete-guide-2026
- **Добавлено:** 2026-10-12 · **Проверено:** 2026-10-12

## Skills: установка, поиск, коллекции

### vercel-labs/skills (CLI `npx skills` + skill `find-skills`)
- **id:** `vercel-skills-cli`
- **Тип:** репозиторий (инфраструктура: установщик и поиск Skills)
- **Что это:** CLI для поиска и установки Skills в 75+ агентов: `npx skills find <запрос>`, `add`, `list`, `update`, `remove`, `init`. Skill `find-skills` учит агента самому искать подходящие Skills под задачу пользователя.
- **Когда полезно:** быстро найти готовый Skill и поставить его в нужный агент (у каждого агента свои папки — CLI это знает).
- **Ограничения и риски:** CLI собирает анонимную телеметрию — отключается `DISABLE_TELEMETRY=1` или `DO_NOT_TRACK=1`. `find-skills` оценивает Skills по популярности (установки, звёзды, «известный автор») и предлагает ставить с флагами `-g -y` (глобально, без подтверждения). Популярность ≠ безопасность: исследование Snyk (02.2026) нашло вредоносные Skills в открытых реестрах. Рекомендация: использовать поиск, а установку — только после ревью и без `-y`.
- **Факты:** ~33.3k ★, MIT, 709 открытых issues.
- **Метка:** ADAPT
- **Статус:** active
- **Источники:** https://github.com/vercel-labs/skills · https://github.com/vercel-labs/skills/tree/main/skills/find-skills
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### DietrichGebert/ponytail
- **id:** `ponytail`
- **Тип:** репозиторий (Skill / AGENTS.md-инструкция)
- **Что это:** заставляет агента перед написанием кода пройти «лестницу» из 7 вопросов: нужно ли это вообще → есть ли уже в коде → в стандартной библиотеке → в платформе → в установленных пакетах → решается ли одной строкой → только потом минимальный код.
- **Когда полезно:** агент пишет слишком много кода; хочется меньше кода, дешевле и быстрее. Идею можно перенести в свои инструкции даже без установки.
- **Ограничения и риски:** [вендор] на одном FastAPI+React-репозитории −54 % строк, −20 % стоимости, −27 % времени — это замер автора на одном проекте, независимой проверки нет; заявление «100 % безопасности» — маркетинг.
- **Факты:** ~157k ★, MIT, 20+ агентов.
- **Метка:** STUDY
- **Статус:** active
- **Источники:** https://github.com/DietrichGebert/ponytail
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

- **Тип:** репозиторий (самообучающийся open-source агент)

Не открывать им чужие репозитории, пока не выйдет исправление.

## Доступ к моделям: прокси и маршрутизация

### tashfeenahmed/freellmapi (FreeLLMAPI)
- **id:** `freellmapi`
- **Тип:** репозиторий (самостоятельно разворачиваемый прокси к бесплатным тарифам LLM)
- **Что это:** локальный сервер с одним OpenAI-совместимым адресом `/v1` (есть и формат Anthropic Messages, и MCP-сервер `/mcp`), за которым собраны бесплатные лимиты многих провайдеров — [вендор] 34 провайдера, ~635 бесплатных эндпоинтов. Роутер выбирает модель по стратегии (баланс, скорость, «умнее», надёжность или вручную) и при упоре в лимит (429/5xx) переключается на следующую, ведёт счётчики лимитов по каждому ключу. Ключи провайдеров хранятся зашифрованными (AES-256-GCM, SQLite); приложения ходят по одному общему ключу.
- **Когда полезно:** эксперименты, прототипы, учёба, личные агенты и скрипты, где важна цена, а не стабильность; подключить к Claude Code, Codex или своему коду как «бесплатный» запасной уровень в маршрутизации по сложности (см. `methods.md` → `model-routing`).
- **Ограничения и риски:** [вендор] «только для личных экспериментов», «без фронтирных моделей, переменная задержка, без SLA»; качество падает к вечеру, когда сильные модели исчерпывают дневные лимиты. Квоты не добавляет — только складывает ваши бесплатные лимиты (заявленные «миллиарды токенов в месяц» — потолок при всех подключённых провайдерах). Запросы уходят к сторонним провайдерам — бесплатные тарифы часто используют данные для обучения: не отправлять личное и рабочее. Условия провайдеров: один аккаунт на провайдера, не перепродавать и не раздавать доступ, не строить на этом продакшн [вторичный]. Быстрая установка — `curl … | bash` с freellmapi.co (скрипт не проверен) — не использовать: ставить из клона репозитория (Docker Compose или `npm`, Node 20+) после чтения кода. Роутер дважды в день скачивает каталог моделей с freellmapi.co (подписан, ключ Ed25519 зашит) — внешняя зависимость; свежий каталог — платный (Premium $19/год или $49 навсегда), бесплатный обновляется раз в месяц. Режим `DEV_MODE` не использовать с реальными ключами. Код не читался.
- **Факты:** ~29.3k ★, ~4.1k форков, MIT, ~808 коммитов (10.2026). Есть приложения для macOS и Windows.
- **Метка:** STUDY
- **Статус:** active
- **Источники:** https://github.com/tashfeenahmed/freellmapi · [вторичный] https://betterstack.com/community/guides/ai/freellmapi/
- **Добавлено:** 2026-10-12 · **Проверено:** 2026-10-12

## Творческие инструменты с ИИ

### ArtCraft (`storytold`): ArtCraft и «Crafting Apps»
- **id:** `artcraft-storytold`
- **Тип:** репозиторий (организация: desktop-приложение для ИИ-генерации + набор открытых аналогов Adobe)
- **Что это:** две линейки. 1) **ArtCraft** — «IDE для управляемой ИИ-генерации картинок и видео»: 3D/2D-композиция сцены, позы персонажей, перенос внешности, image-to-3D, плюс обычные text-to-image / image-to-video через сторонние модели (Nano Banana, GPT-Image, Seedream, Flux, Veo, Kling, Sora 2, Grok, Midjourney и др.). 2) **Crafting Apps** на Rust — открытые «clean-room» аналоги Photoshop (PhotoCraft), Lightroom, Premiere, Illustrator, Acrobat, PowerPoint, Excel, AutoCAD, Pro Tools; [вендор] написаны ИИ-агентами (Claude Code) за считанные недели; у PhotoCraft есть управление внешними агентами через CLI, JSON-канал и MCP-сервер.
- **Когда полезно:** ArtCraft — когда нужен контроль композиции и поз в ИИ-картинках/видео вместо «рулетки» промптов; Crafting Apps — бесплатная альтернатива для простых задач и редактор, которым может управлять ИИ-агент через MCP.
- **Ограничения и риски:** [вендор] Crafting Apps — ранняя альфа, «не замена Photoshop для ежедневной профессиональной работы»; [независимо] сходство с Adobe во многом внешнее, есть баги и пробелы (OMG! Ubuntu, 08.10.2026); юридический статус «clean-room» при разработке ИИ ставится под сомнение (Phoronix, 07.10.2026); звёзды выросли до десятков тысяч за неделю — повод проверять внимательнее, а не доверять больше; ArtCraft в основном вызывает платные облачные модели (свои ключи/аккаунты); в корне репозитория artcraft есть `.env` и папка `secrets` — проверить, что там нет реальных ключей; код не читался.
- **CADCraft (`storytold/cadcraft`, проверено 2026-10-22):** открытый 2D-CAD на Rust в стиле AutoCAD (3D заявлен, готов ≈ 2 % по `ROADMAP.md`): командная строка, привязки, слои, размеры, штриховки, блоки, параметрические зависимости, листы и печать в PDF; macOS/Windows/Linux/FreeBSD и браузер (WebAssembly). Интерфейс в т.ч. на русском (перевод частичный, недостающее — по-английски). Файлы: DXF (чтение R12–2018), DWG (чтение через библиотеку acadrust; R13/R14 не проверены, 2018 — только на синтетических файлах), запись DXF/DWG (версии в документации расходятся: R2000 или 2000–2018); экспорт PDF/SVG/PNG. Для агентов — MCP-сервер (`cadcraft-cli mcp`: ввод команд, просмотр чертежа, рендер в PNG, а при подключении к открытому приложению — скриншот и клик по интерфейсу) и CLI для пакетной конвертации. Через MCP агент может запускать LISP и скрипты и сохранять файлы.
