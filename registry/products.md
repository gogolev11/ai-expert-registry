## Готовые приложения (уровни 1–3 лестницы архитектуры)

### Claude (приложение): Projects + Skills + задачи по расписанию
- **id:** `claude-app`
- **Тип:** продукт
- **Что это:** чат-приложение Anthropic (веб, desktop, мобильное), которое умеет больше, чем чат: проекты с общими инструкциями и базой знаний, Skills (папки-инструкции, загружаемые по необходимости), подключения к сервисам (connectors), выполнение кода и работу с файлами, публикацию страниц (artifacts), задачи по расписанию, управление браузером и компьютером.
- **Когда полезно:** первый кандидат почти для любой личной задачи — от «спросить» до «каждую неделю собирать отчёт». Часто закрывает задачу без API и своего кода.
- **Ограничения и риски:** общий недельный лимит подписки на чат, Claude Code и задачи по расписанию; при автоматизации следить за расходом.
- **Статус:** active
- **Источники:** https://support.claude.com · https://www.anthropic.com/news
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

## Агенты для программирования

### Claude Code
- **id:** `claude-code`
- **Тип:** продукт (coding agent: терминал, IDE, desktop, веб)
- **Что это:** агент Anthropic, который читает и меняет код, запускает команды и тесты. Поддерживает subagents, Skills, plugins, hooks, MCP.
- **Когда полезно:** реальная разработка: фичи, рефакторинг, отладка, работа в репозитории.
- **Ограничения и риски:** при широких правах может выполнять опасные команды — работать в отдельной ветке, проверять настройки разрешений; plugins и hooks сторонних авторов — проверять.
- **Статус:** active
- **Источники:** https://docs.claude.com/en/docs/claude-code/overview
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### OpenAI Codex
- **id:** `openai-codex`
- **Тип:** продукт (coding agent: CLI, облако, desktop) + open-source CLI `openai/codex`
- **Что это:** агент OpenAI для программирования. На DevDay 29.09.2026: облачный запуск, обновлённый CLI с голосовым управлением, Code Review в desktop, Codex Security Cloud (сканирование репозиториев на уязвимости).
- **Когда полезно:** если основная подписка — ChatGPT, или нужна модель GPT-6.1 Sol / Astra Ultrafast.
- **Ограничения и риски:** Astra и Ultrafast — только на дорогих тарифах (Pro 500, Enterprise).
- **Статус:** active
- **Источники:** https://openai.com/index/devday-2026-recap/ · https://github.com/openai/codex
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

## API и платформы для разработчиков

### OpenAI Decisions API
- **id:** `openai-decisions-api`
- **Тип:** фича API
- **Что это:** анонсирован на DevDay 29.09.2026. API, которое не генерирует текст, а выбирает ответ из заранее заданного конечного списка — для классификации, маршрутизации запросов, выбора действия агента. Принимает текст и изображения. [вторичный] работает на GPT-6 Luna; [вендор, через вторичный] ~150 мс против ~1,6 с у обычного вызова.
- **Когда полезно:** те же задачи, что у Jev, но нужен вход с изображениями или вы уже в экосистеме OpenAI.
- **Ограничения и риски:** limited preview (доступ не у всех); на 30.09.2026 не опубликованы цены, схемы запросов и эндпоинты. Пока сравнивать с Jev невозможно — ждать публичного релиза.
- **Статус:** watch
- **Источники:** https://openai.com/index/devday-2026-recap/ · [вторичный] https://www.firecrawl.dev/blog/openai-decisions-api-vs-jev
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### OpenAI Agents API (с Computer Use)
- **id:** `openai-agents-api`
- **Тип:** платформа API
- **Что это:** API для агентов, которые работают с программами (computer use), с поддержкой нескольких агентов, поиска инструментов (tool search) и сжатия контекста (compaction). Анонсирован на DevDay 2026; есть вариант запуска целиком в AWS (Bedrock Managed Agents).
- **Когда полезно:** строите своего агента на моделях OpenAI и не хотите писать цикл агента и управление контекстом сами.
- **Ограничения и риски:** привязка к вендору; computer use — медленный и рискованный способ, использовать только если нет API/connector.
- **Статус:** active
- **Источники:** https://openai.com/index/devday-2026-recap/
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### Claude Developer Platform: prompt caching + Batch API
- **id:** `claude-api-cost-features`
- **Тип:** фичи API
- **Что это:** две встроенные возможности Claude API для снижения цены. Prompt caching: повторяющееся начало запроса кэшируется, чтение из кэша стоит ~10 % обычной цены входа (запись дороже: ×1,25 на 5 мин, ×2 на 1 ч). Batch API: асинхронная обработка со скидкой 50 %, большинство пакетов за час, максимум 24 ч.
- **Когда полезно:** длинные одинаковые инструкции/документы в каждом запросе (кэш); большие объёмы без спешки (batch).
- **Ограничения и риски:** кэш сбрасывается при изменении начала запроса (инструменты, системный промпт); batch — не для интерактива.
- **Статус:** active
- **Источники:** https://platform.claude.com/docs/en/build-with-claude/prompt-caching · https://platform.claude.com/docs/en/build-with-claude/batch-processing
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### OpenRouter
- **id:** `openrouter`
- **Тип:** сервис (единый API ко многим моделям)
- **Что это:** один ключ и один формат запросов для сотен моделей разных вендоров и провайдеров; удобно сравнивать цены и переключаться.
- **Когда полезно:** нужно быстро попробовать/сравнить модели или использовать модели, которых нет у основных вендоров (например, Jev).
- **Ограничения и риски:** посредник между вами и вендором — ещё одна сторона, видящая данные; проверять политику хранения данных у конкретного провайдера.
- **Статус:** active
- **Источники:** https://openrouter.ai/models
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07
