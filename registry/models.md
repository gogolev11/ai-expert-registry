## Anthropic (Claude)

### Claude Opus 5.5
- **id:** `claude-opus-5-5`
- **Тип:** модель (флагман, рекомендуемая по умолчанию)
- **Что это:** основная мощная модель Anthropic для долгой агентной работы с кодом и знаниями. Вышла 22.09.2026.
- **Когда полезно:** большинство сложных задач — агентное программирование, исследования, длинные документы. Anthropic прямо рекомендует начинать с неё и переходить на Fable 5.1, только если Opus не справляется.
- **Ограничения и риски:** дороже Sonnet в 2 раза; для простых массовых подзадач избыточна.
- **Факты:** $4 / $20; контекст 1M токенов; вывод до 128K; API-имя `claude-opus-5-5`. [вендор] по качеству близка к Fable 5.1 при цене на ~40 % ниже Opus 5.
- **Статус:** active
- **Источники:** https://platform.claude.com/docs/en/about-claude/models/overview · https://www.anthropic.com/news
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### Claude Sonnet 5.5
- **id:** `claude-sonnet-5-5`
- **Тип:** модель (баланс скорость/качество)
- **Что это:** средняя модель линейки, вышла 28.09.2026. [вендор] на ~30 % быстрее и до 30 % дешевле Sonnet 5.
- **Когда полезно:** повседневная работа, чат-боты, большинство API-сценариев, где Opus избыточен.
- **Ограничения и риски:** на самых длинных агентных задачах уступает Opus 5.5.
- **Факты:** $2 / $10; чтение кэша $0.10 (с 07.10.2026 снижено с $0.20, −50 %); контекст 1M; вывод до 128K; `claude-sonnet-5-5`. Ломающие изменения от Sonnet 5: принудительный `tool_choice` (`any`/`tool`) → ошибка 400; отключение мышления — `thinking: {type: "between_tools"}`. Sonnet 4.5 снимается с API 30.11.2026 — замена Sonnet 5.5.
- **Статус:** active
- **Источники:** https://platform.claude.com/docs/en/about-claude/models/overview · https://platform.claude.com/docs/en/release-notes/overview · https://platform.claude.com/docs/en/about-claude/model-deprecations
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-08

### Claude Fable 5.1 / Claude Mythos 5.1
- **id:** `claude-fable-mythos-5-1`
- **Тип:** модель (высший уровень, Mythos-tier)
- **Что это:** самые сильные модели Anthropic (вышли 01.09.2026). Одна базовая модель: Fable 5.1 — публичная версия с доп. защитами в биологии, кибербезопасности и ИИ-R&D; Mythos 5.1 — доступ только для узкого круга организаций.
- **Когда полезно:** самые трудные задачи на рассуждение и очень длинные агентные задачи, где Opus 5.5 по проверке не дотягивает.
- **Ограничения и риски:** в 2,5 раза дороже Opus 5.5. Летом 2026 доступ временно приостанавливался из-за экспортного контроля США (12.06–01.07.2026) — учитывать риск доступности.
- **Факты:** Fable 5.1 — $10 / $50; контекст 1M; вывод до 128K; `claude-fable-5-1`.
- **Статус:** active
- **Источники:** https://platform.claude.com/docs/en/about-claude/models/overview · https://www.anthropic.com/news/fable-mythos-access
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### Claude Haiku 5.5
- **id:** `claude-haiku-5-5`
- **Тип:** модель (быстрая и дешёвая)
- **Что это:** самая быстрая и дешёвая модель Claude, вышла 07.10.2026. Сделана для массовой работы, где важны цена и задержка: классификация, извлечение данных, маршрутизация, subagents.
- **Когда полезно:** простые массовые подзадачи и «дешёвый уровень» в маршрутизации по сложности. По цене теперь в одной категории с GPT-6 Luna, но с контекстом 1M.
- **Ограничения и риски:** цена зависит от длины запроса — запрос длиннее 100K токенов стоит в 5 раз дороже (не путать «контекст 1M» с «дёшево на 1M»). Ломающие изменения при переходе с Haiku 4.5: `thinking: {type: "enabled", budget_tokens: N}` → ошибка 400; адаптивное мышление включено по умолчанию (ответ может начинаться с блоков `thinking`); тот же текст занимает больше токенов. Перед заменой — прогнать свои примеры (evals).
- **Факты:** запрос ≤100K токенов — $0.10 / $0.50 (чтение кэша $0.01); >100K — $0.50 / $2.50; Batch — ещё −50 %. Контекст 1M; вывод до 128K; параметр effort; `claude-haiku-5-5`. Доступна в Claude API, Bedrock, Google Cloud, Microsoft Foundry. [вывод] в 10 раз дешевле Haiku 4.5 ($1 / $5) на коротких запросах.
- **Статус:** active
- **Источники:** https://platform.claude.com/docs/en/about-claude/models/overview · https://platform.claude.com/docs/en/about-claude/pricing · https://platform.claude.com/docs/en/release-notes/overview (07.10.2026)
- **Добавлено:** 2026-10-08 · **Проверено:** 2026-10-08

## Google (Gemini)

### Gemini 4 Argon
- **id:** `gemini-4-argon`
- **Тип:** модель (новый флагман Google, первая модель Gemini 4)
- **Что это:** анонсирована 30.09.2026 как самая мощная модель Google: сложная разработка, «офисная» знаниевая работа, киберзащита. Лимит вывода — 1M токенов (у предыдущих — 64K).
- **Когда полезно:** сравнивать с Claude Opus 5.5 / GPT-6 Astra на задачах с очень длинным выводом (генерация больших документов, массовые правки кода за один ответ) и в экосистеме Google — когда станет доступна.
- **Ограничения и риски:** на 08.10.2026 **широкого доступа нет**: сначала доверенные специалисты по киберзащите (Fairwind Program), затем платные клиенты API и подписчики Google AI Ultra («скоро»). API-имя и контекст официально не опубликованы. [независимо] модель тратит много токенов вывода (~62K на задачу против ~27K у GPT-6 Astra) — дешевизна за токен частично съедается объёмом.
- **Факты:** вводная цена $2 / $10 (кэшированный вход −95 %), после вводного периода — $4 / $20; дата окончания скидки не объявлена. [вендор] DeepSWE v1.1 — 77,9 %, AutomationBench — 51,3 % (1-е место). [независимо, Artificial Analysis] Intelligence Index 53 — на уровне GPT-6 Astra (53) и GPT-6.1 Sol (52); на Terminal Bench 4 — 57 % против 60 % у Claude Opus 5.5 и 64 % у Sonnet 5.5.
- **Статус:** watch
- **Источники:** https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/ · [независимо] https://artificialanalysis.ai/articles/gemini-4-argon-google-top-three-labs
- **Добавлено:** 2026-10-08 · **Проверено:** 2026-10-08

## Специализированные модели

### Jev 1.13 (TypeSafe) — decision-модель
- **id:** `jev`
- **Тип:** модель (новая категория: «System One» decision model)
- **Что это:** модель, которая не пишет текст, а **выбирает ответ** из заданных вариантов и возвращает типизированный результат с вероятностями по вариантам. Три типа вопросов: выбор (Choice), оценка по шкале (Score), вероятность условия. Вышла в сентябре 2026 (OpenRouter: 18.09.2026). Сделана TypeSafe AI — компанией экс-исследователя OpenAI.
- **Когда полезно:** маршрутизация запросов между моделями, классификация, выбор следующего действия агента, модерация — везде, где ответ из конечного списка. Дёшево, быстро, предсказуемо.
- **Ограничения и риски:** только текст на входе (без изображений); контекст 32K; молодой продукт небольшой компании.
- **Факты:** $0.042 за 1M входных токенов, выходные токены бесплатны. Доступна через TypeSafe и OpenRouter.
- **Статус:** active
- **Источники:** https://openrouter.ai/typesafe/jev-1.13 · [вторичный] https://www.firecrawl.dev/blog/openai-decisions-api-vs-jev
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

Локальный запуск 1T-модели — только на серьёзном кластере.
- **Факты:** API (Mistral Studio, preview) — $1.36 / $4.18. [вендор] DeepSWE v1.1 — 61,7 %, Terminal-Bench 4 — 28,3 %, AutomationBench — 59,9 %.
