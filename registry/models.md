## Anthropic (Claude)

### Claude Opus 5.5
- **id:** `claude-opus-5-5`
- **Тип:** модель (флагман, рекомендуемая по умолчанию)
- **Что это:** основная мощная модель Anthropic для долгой агентной работы с кодом и знаниями. Вышла 22.09.2026.
- **Когда полезно:** большинство сложных задач — агентное программирование, исследования, длинные документы. Anthropic прямо рекомендует начинать с неё и переходить на Fable 5.1, только если Opus не справляется.
- **Ограничения и риски:** дороже Sonnet в 2 раза; для простых массовых подзадач избыточна.
- **Факты:** $4 / $20; контекст 1M токенов; вывод до 128K; API-имя `claude-opus-5-5`. [вендор] по качеству близка к Fable 5.1 при цене на ~40 % ниже Opus 5.
- **Статус:** active
- **Источники:** https://platform.claude.com/docs/en/about-claude/models/overview · https://www.anthropic.com/news
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

- **Ограничения и риски:** на самых длинных агентных задачах уступает Opus 5.5.

### Claude Fable 5.1 / Claude Mythos 5.1
- **id:** `claude-fable-mythos-5-1`
- **Тип:** модель (высший уровень, Mythos-tier)
- **Что это:** самые сильные модели Anthropic (вышли 01.09.2026). Одна базовая модель: Fable 5.1 — публичная версия с доп. защитами в биологии, кибербезопасности и ИИ-R&D; Mythos 5.1 — доступ только для узкого круга организаций.
- **Когда полезно:** самые трудные задачи на рассуждение и очень длинные агентные задачи, где Opus 5.5 по проверке не дотягивает.
- **Ограничения и риски:** в 2,5 раза дороже Opus 5.5. Летом 2026 доступ временно приостанавливался из-за экспортного контроля США (12.06–01.07.2026) — учитывать риск доступности.
- **Факты:** Fable 5.1 — $10 / $50; контекст 1M; вывод до 128K; `claude-fable-5-1`.
- **Статус:** active
- **Источники:** https://platform.claude.com/docs/en/about-claude/models/overview · https://www.anthropic.com/news/fable-mythos-access
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

## Специализированные модели

### Jev 1.13 (TypeSafe) — decision-модель
- **id:** `jev`
- **Тип:** модель (новая категория: «System One» decision model)
- **Что это:** модель, которая не пишет текст, а **выбирает ответ** из заданных вариантов и возвращает типизированный результат с вероятностями по вариантам. Три типа вопросов: выбор (Choice), оценка по шкале (Score), вероятность условия. Вышла в сентябре 2026 (OpenRouter: 18.09.2026). Сделана TypeSafe AI — компанией экс-исследователя OpenAI.
- **Когда полезно:** маршрутизация запросов между моделями, классификация, выбор следующего действия агента, модерация — везде, где ответ из конечного списка. Дёшево, быстро, предсказуемо.
- **Ограничения и риски:** только текст на входе (без изображений); контекст 32K; молодой продукт небольшой компании.
- **Факты:** $0.042 за 1M входных токенов, выходные токены бесплатны. Доступна через TypeSafe и OpenRouter.
- **Статус:** active
- **Источники:** https://openrouter.ai/typesafe/jev-1.13 · [вторичный] https://www.firecrawl.dev/blog/openai-decisions-api-vs-jev
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

## Open-weight модели (веса можно скачать и запустить у себя)

### DeepSeek V4
- **id:** `deepseek-v4`
- **Тип:** модель (open-weight, MIT)
- **Что это:** флагман DeepSeek с открытыми весами: контекст 1M, разреженная архитектура (MoE). Чекпоинты V4 Flash и V4 Pro.
- **Когда полезно:** нужна сильная модель на своём железе или у дешёвого провайдера; строгие требования к данным.
- **Ограничения и риски:** для самостоятельного запуска нужен серьёзный GPU-кластер; при использовании API DeepSeek данные уходят в Китай — оценивать требования приватности.
- **Статус:** active

- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07
