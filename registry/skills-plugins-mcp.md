### Agent Skills (открытый стандарт)
- **id:** `agent-skills-standard`
- **Тип:** стандарт
- **Что это:** формат «папка с `SKILL.md` + справочники/скрипты», который учит агента делать определённый тип задач. Агент сначала видит только имя и описание (~десятки токенов), полный текст подгружает по необходимости. Изначально от Anthropic, поддерживается Claude, Codex/ChatGPT, Gemini CLI, Copilot, Cursor и многими другими.
- **Когда полезно:** повторяющаяся задача, которую надоело объяснять заново; перенос экспертизы между агентами.
- **Ограничения и риски:** совместимость формата ≠ совместимость конкретного Skill (имена инструментов, hooks, сеть). Skill исполняется с вашими правами — сторонние проверять.
- **Статус:** active
- **Источники:** https://agentskills.io/specification
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### Model Context Protocol (MCP)
- **id:** `mcp`
- **Тип:** стандарт
- **Что это:** единый «разъём» для подключения инструментов и данных к ИИ-приложениям и агентам. Многие connectors построены на нём; на DevDay 2026 OpenAI добавил MCP Events (MCP как триггер автоматизаций).
- **Когда полезно:** нужного готового connector нет, а интеграцию хочется использовать в нескольких ИИ-клиентах.
- **Ограничения и риски:** каждый подключённый MCP-сервер добавляет описания инструментов в контекст (сотни токенов на сложный инструмент) и получает доступ к данным — сторонний код, проверять. **Ревизия спецификации 2026-07-28** (кандидат в релиз; финальный текст сверить на modelcontextprotocol.io): убраны сессии (нет handshake initialize и заголовка `Mcp-Session-Id`, сведения о клиенте — в `_meta` каждого запроса), возможности — через `server/discover`; Roots, Sampling, Logging, HTTP+SSE и Dynamic Client Registration объявлены устаревшими (удаление не раньше 28.07.2027). Для своих MCP-серверов — планировать миграцию. **Безопасность (10.2026):** MCP Python SDK до 1.30.0 / 2.2.0 — захват OAuth-аккаунта вредоносным сервером (обновить); LiteLLM как MCP-шлюз — обход аутентификации CVE-2026-59822, [вторичный] внесён в каталог активно эксплуатируемых уязвимостей CISA KEV (обновить, сменить master key).
- **Статус:** active
- **Источники:** https://modelcontextprotocol.io · https://openai.com/index/devday-2026-recap/ · https://aaif.io/blog/mcp-2026-07-28-whats-changing-and-how-to-migrate · https://cycode.com/blog/mcp-python-sdk-oauth-account-takeover/ · https://www.wiz.io/blog/off-guard-breaking-litellm-from-authentication-bypass-to-cloud-compromise · [вторичный] https://adversa.ai/blog/top-mcp-security-resources-october-2026/
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-08

### trailofbits/skills
- **id:** `trailofbits-skills`
- **Тип:** репозиторий (официальные security-Skills от Trail of Bits)
- **Что это:** 40+ Skills для аудита кода, смарт-контрактов, статического анализа от известной компании по безопасности.
- **Когда полезно:** проверка безопасности кода силами агента.
- **Ограничения и риски:** лицензия CC-BY-SA-4.0 (share-alike — учитывать при переделке).
- **Факты:** ~7k ★ (10.2026); Claude Code (marketplace), Codex.
- **Метка:** ADAPT
- **Статус:** active
- **Источники:** https://github.com/trailofbits/skills
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### Риск экосистемы: вредоносные Skills в открытых реестрах
- **id:** `skills-supply-chain-risk`
- **Тип:** предупреждение безопасности
- **Что это:** Snyk (февраль 2026) проверил 3 984 Skills из ClawHub и skills.sh: у ~37 % есть хотя бы одна уязвимость, у ~13 % — критическая, 76 — подтверждённо вредоносные. Вредоносный Skill может не содержать кода — достаточно текстовой инструкции агенту.
- **Когда полезно:** помнить при любой установке Skill/plugin/MCP: реестр и популярность ≠ проверка.
- **Статус:** active
- **Источники:** https://snyk.io/blog/toxicskills-malicious-ai-agent-skills-clawhub/
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07

### Риск экосистемы: атаки на coding-агентов через чужие репозитории и plugins
- **id:** `coding-agent-repo-plugin-attacks`
- **Тип:** предупреждение безопасности
- **Что это:** в сентябре 2026 опубликована серия атак, где агент запускает чужой код без вашего подтверждения — просто потому что открыл репозиторий или обновил plugin:
  - **GitSpawn** (01.09.2026): репозиторий, полученный файлами вместе с папкой `.git` (архив, диск, общая папка), через `.git/config` (`core.fsmonitor`) запускает команду, когда агент в фоне вызывает `git status` — вне песочницы и до запроса доверия. Исправлено: Claude Code 2.1.196, Cursor, Codex, Goose 1.44.0. Не исправлено на дату публикации: Hermes Agent, Qwen Code, Grok Build, а также путь `ultrareview` в Claude Code.
  - **Plugin4Shell** (17.09.2026): автор plugin подменяет закреплённый коммит веткой с именем этого SHA — при авто-обновлении ставится вредоносный код без действий пользователя. Исправлено: Claude Code 2.1.179, Codex 0.146.0. GitHub Copilot — исправления не было; Gemini CLI — снят Google с поддержки, исправления не будет.
  - **Троянские hooks в обновлениях plugins** (исследование, 09.2026): обновление, добавляющее hook, захватывало агент до 92,5 % случаев; стандартные сканеры пропустили почти половину образцов.
- **Когда полезно:** помнить при любом открытии чужого кода агентом и при установке plugins. Практика: держать агенты обновлёнными; перед открытием чужого репозитория из архива смотреть `.git/config`; ставить plugins только от доверенных авторов и проверять их hooks после обновлений; не держать ключи (облако, кошельки, SSH) в окружении агента.
- **Статус:** active
- **Источники:** https://www.manifold.security/blog/ai-coding-agents-git-hijack · https://www.air.security/blog-posts/plugin4shell · https://arxiv.org/abs/2609.03884 · [вторичный, обзор] https://adversa.ai/blog/top-ai-coding-agent-security-resources-october-2026
- **Добавлено:** 2026-10-08 · **Проверено:** 2026-10-08
