# Архив

Записи, удалённые из реестра после одобрения. Формат: запись целиком + поля **Удалено:** дата и **Причина:**.

---

### Claude Haiku 4.5
- **id:** `claude-haiku-4-5`
- **Тип:** модель (быстрая и дешёвая)
- **Что это:** самая быстрая модель Claude с близким к флагманам интеллектом.
- **Когда полезно:** простые массовые подзадачи — классификация, извлечение данных, маршрутизация, subagents.
- **Ограничения и риски:** контекст 200K (меньше, чем у 5.x). Anthropic анонсировала Haiku 5.5 — ждать замены.
- **Факты:** $1 / $5; вывод до 64K; `claude-haiku-4-5-20251001`.
- **Статус:** active
- **Источники:** https://platform.claude.com/docs/en/about-claude/models/overview
- **Добавлено:** 2026-10-07 · **Проверено:** 2026-10-07
- **Удалено:** 2026-10-08
- **Причина:** полностью вытеснена Claude Haiku 5.5 (07.10.2026): в 10 раз дешевле на запросах до 100K токенов ($0.10 / $0.50 против $1 / $5), контекст 1M против 200K. Сама модель ещё доступна в API (снятие не раньше 15.10.2026, официальной даты нет) — нужна только для старых интеграций с `budget_tokens`.
