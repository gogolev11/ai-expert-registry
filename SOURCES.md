# Источники

Порядок доверия: официальная документация → changelog / release notes → официальные страницы
цен → model cards → официальные GitHub-организации → независимые бенчмарки → обзоры и сообщества.
Обзоры и `awesome-*` каталоги — **только для поиска кандидатов**; каждая запись подтверждается
первоисточником.
