# Как консультант пользуется реестром

1. В начале чата, где нужен совет по ИИ-инструментам, подключить репозиторий
   `gogolev11/ai-expert-registry` (только чтение) и прочитать нужные файлы `registry/`.
   Простой вопрос — достаточно одного файла по теме.
2. Отвечать по процессу скилла `ai-stack-architect`: задача → результат → способности →
   минимальная архитектура → готовые решения → конкретные инструменты.
3. На шаге «готовые решения / инструменты» опираться на реестр и ссылаться на записи:
   «по реестру (проверено ГГГГ-ММ-ДД)…».
4. Если запись старше 30 дней по «Проверено» и от неё зависит решение (цена, доступность,
   версия) — перепроверить поиском и сказать, совпало ли.
5. Если в реестре нет нужного — искать в интернете; если находка значима по `CRITERIA.md`,
   предложить пользователю добавить её (через PR, не напрямую в `main`).
6. Метки репозиториев из реестра не повышать без собственной проверки кода.
